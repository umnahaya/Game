# Guess the Emoji 🎭

A beginner-friendly emoji guessing game built with Python and Streamlit. Guess the word, movie, food, animal, or idea represented by the emojis.

## Project files

- `guess_emoji.py` — terminal-based Python game
- `guess_emoji.ipynb` — Jupyter Notebook version
- `app.py` — interactive Streamlit app
- `requirements.txt` — app dependency list

## Run the Python game

```bash
python guess_emoji.py
```

## Run the Streamlit app

1. Install dependencies:

```bash
pip install -r requirements.txt
```

2. Run the app:

```bash
streamlit run app.py
```

## How to play

- Look at the emojis shown on screen.
- Type what you think they represent.
- Submit your answer to see if it's correct.
- Continue through all questions and check your final score.
- Use **Play Again** to start a new round.

## Technologies

- Python
- Streamlit
- Jupyter Notebook
- `random` module

Created as a beginner Python project for practice and learning.
